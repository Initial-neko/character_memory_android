# V1 聊天候选集成

当前分支集成表情套装网格、持久语音状态、最近 1H Usage、一键生图草稿、ASR 输入与按需 TTS。所有客户端请求仍由 Core/Media 当前接口提供；模型与持久化留在 PC。

ASR 单次最长 30 秒、16 kHz mono PCM16；用户授权后录音，结束后调用 Media `/v1/asr`，转写保持为可编辑未发送草稿。点击加入输入框后仍需手动发送。取消、后台、切换服务器或目标使旧任务失效并释放麦克风。按需朗读调用 Media `/v1/tts` 返回二进制音频，使用私有临时缓存与应用共用播放器；录音与播放互斥，音频焦点丢失或页面退出停止播放。按需朗读使用 Media 的当前默认 voice；角色持久语音由 Core 的 VOICE_MESSAGE 和媒体 ID 决定。

Space 结构化提及、幂等评论与提醒消费依赖 Core #227；该功能及透明九宫 PNG 自动切片已进入 Core 主线。部署必须用实际 OpenAPI 验证 `/v1/space/notifications` 与标记已读路由。已有评论回复的 90 秒等待窗口继续绑定确认凭据，页面重新打开不续期。

聊天输入栏保留一个 ASR 话筒，通话入口位于聊天工具面板。完整通话展示人物、时长、双方字幕、用户麦克风静音/恢复和挂断。授权后自动分段（16 kHz、900 ms 静音、有效发声至少 250 ms、每段最多 12 秒），Media ASR 标记为 `call`。用户静音取消尚未提交的录音、转写及语音队列，已接收的服务器请求继续收回复；恢复不补发旧录音。播放期间自动暂停麦克风，与用户静音独立。

显式通话由不自动重启的 microphone/mediaPlayback 前台服务保持。Home、同一目标页面导航和返回应用继续原通话；其他页面提供返回入口。通知可返回应用和挂断；Android 13+ 用户可在通话页授予通知权限，拒绝通知不会隐式打开麦克风。挂断、切换对象/服务器、服务销毁和 owner 清理释放录音与播放器。识别、确认的视觉问题共用有界串行发送队列；按 event/turn 凭据关联 SSE，群聊按人物顺序朗读。观察回复共用播放器，但不会完成尚未返回的语音请求。接收不明确或回应超时终止通话，提示检查历史，不重复写入；播放失败保留文字并继续流程。

摄像头使用 Camera2：系统授权、前后镜头预览、取一帧、文字询问与明确确认发送。仅内存保存、长边≤1080、JPEG≤2 MiB；退出前台关闭。Direct 和群聊分别使用 Core 当前视觉消息路由。屏幕共享使用系统 MediaProjection 授权及显式前台服务，可在已授权范围内跨 App 共享；冻结服务器/人物/会话，切换目标、停止或系统撤销会关闭投屏并取消上传，拒绝后台自动重启。自动观察只用于 Direct DISPLAY，并遵守 Core 配置间隔和显著变化门槛。

通话页可显示真实相机预览，取帧后明确确认发送；共享当前屏幕的手动问题也进入通话发送队列。网络失败只暂停自动上传并按 2/5/10/30/60 秒上限重试，不撤销投屏授权；自动观察禁用仍可手动询问。服务器拒绝则停止自动重试；系统撤销必须重新授权。状态与停止原因输出结构化 CM_SCREEN 日志。挂断只停止本通话新建的共享，已有普通聊天共享不归通话所有。手机摄像、后台收音、音频焦点及网络切换仍需真机独立验收。

表情面板只有预览解码成功后可发送；Coil SVG 2.7.0 与现有版本配套，支持 Core 默认 SVG 和导入 PNG。重新打开面板先显示现有缓存，再异步刷新活动目录，PC 移除项不继续留在旧目录；刷新失败显示请求错误，历史消息不随目录移除而删除。Android 不提供表情管理入口；PC 库移除依赖 Core 对应实现和部署。加载失败可见且禁发。

自动化新增录音协调器/PCM/传输、通话队列与取消、表情/Usage/持久语音和视觉契约测试；模拟器 gate 为 P2 ≥40 用例及34张指定截图，另保留 P1 全部回归。真机麦克风、扬声器/耳机、后台行为、真实 Core/Media 模型与视觉需独立证据。CALL-01/CALL-02 必须完成对应端到端验证才能标为已验收。

本分支是内部集成候选；构建通过不表示全部 V1 已交付。最终 APK 从合并主线生成，版本必须高于手机已安装版本，并继续使用固定验收签名。
