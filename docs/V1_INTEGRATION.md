# V1 聊天候选集成

当前分支集成表情套装网格、持久语音状态、最近 1H Usage、一键生图草稿、ASR 输入与按需 TTS。所有客户端请求仍由 Core/Media 当前接口提供；模型与持久化留在 PC。

ASR 单次最长 30 秒、16 kHz mono PCM16；用户授权后录音，结束后调用 Media `/v1/asr`，转写保持为可编辑未发送草稿。点击加入输入框后仍需手动发送。取消、后台、切换服务器或目标使旧任务失效并释放麦克风。按需朗读调用 Media `/v1/tts` 返回二进制音频，使用私有临时缓存与应用共用播放器；录音与播放互斥，音频焦点丢失或页面退出停止播放。按需朗读使用 Media 的当前默认 voice；角色持久语音由 Core 的 VOICE_MESSAGE 和媒体 ID 决定。

Space 结构化提及、幂等评论与提醒消费依赖 Core 对应功能。当前生产服务没有 `/v1/space/notifications`；该依赖未部署前，候选不能作为统一验收交付。已有评论回复的 90 秒等待窗口继续绑定确认凭据，页面重新打开不续期。

完整通话使用单独的前台会话协调器，授权后自动分段（16 kHz、900 ms 静音、有效发声至少 250 ms、每段最多 12 秒），Media ASR 标记为 `call`。识别后向当前绑定的 Core 会话发送一次，等待阶段可继续录音并排队；按持久回复来源关联 SSE，群聊按人物顺序朗读。播放期间暂停麦克风以避免回声，播放失败保留文字并继续流程。挂断、切换对象/服务器、离开聊天或后台会清理任务、麦克风与播放器；接收不明确或回应超时终止通话，提示检查历史，不重试写入。

自动化新增录音协调器/PCM/传输、通话队列与取消、表情/Usage/持久语音测试；模拟器 gate 为 P2 ≥36 用例及18张指定截图，另保留 P1 全部回归。真机麦克风、扬声器/耳机、后台行为、真实 Core/Media 模型与视觉需独立证据。CALL-01/CALL-02 必须完成对应端到端验证才能标为已验收。

本分支是内部集成候选；构建通过不表示全部 V1 已交付。最终 APK 从合并主线生成，版本必须高于手机已安装版本，并继续使用固定验收签名。
